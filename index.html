FAQ

Questions, answered

What's the difference between web hosting and a VPS?

Web hosting is fully managed — ideal for websites and WordPress. A VPS is your own virtual server with root access, so you can install any software, but you (or our managed service) look after it.

Can you move my existing website for me?

Yes. Migrations from other providers are free on all annual plans. Send us your current host details and we'll handle the move with minimal downtime.

Which operating systems can I run?

Ubuntu, Debian, AlmaLinux, Rocky Linux and Windows Server (licence extra) on VPS plans. Containers support most popular Linux distributions.

How do payments work?

Pay monthly or annually by mobile money, bank transfer or card. There are no setup fees and you can upgrade at any time.

Do you take backups?

Every plan includes automated daily backups stored on separate hardware. You can request restores at any time, and VPS customers can also take their own snapshots.

Can I upgrade later?

Absolutely. Add CPU, RAM or storage whenever you need — VPS upgrades usually take just a reboot, with no data migration.
